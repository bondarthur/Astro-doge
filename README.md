# ASTRO DODGE

A minimal retro 90's-style pixel web game. Open `index.html` in any browser — no build, no dependencies.

## How to play
- **Arrow keys**: move the astronaut (laptop/desktop)
- **Touch**: drag anywhere to move — the astronaut follows your finger (phones/tablets); tap to start/retry
- **Enter / Space**: start or retry
- **M**: toggle sound

Dodge interstellar objects (asteroids, planets, comets, UFOs, satellites). The longer you survive, the more objects spawn and the faster everything moves:

- **0–2:30 — Phase 1: DRIFT** (easy)
- **2:30–4:00 — Phase 2: STORM** (challenging)
- **4:00+ — Phase 3: CHAOS** (hardcore)

Score grows with survival time, plus **+1,000,000 bonus points every 1:30 survived**. Best score is saved locally.

## Easter eggs
Rare one-time objects drift through some runs — about one in **two** plays hides a common oddity (a lost astronaut, a space squirrel, a giraffe, a rubber duck), and about one in **twenty** plays a legendary one (a Tesla roadster, the ISS, the Eiffel Tower, an alien). They still hurt if you touch them.
